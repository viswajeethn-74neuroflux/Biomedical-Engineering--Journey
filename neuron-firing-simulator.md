Neuron Firing Simulator

Project Overview

This project is a simple Python program that demonstrates the basic concept of neuronal signal integration and threshold firing.

Objective

To understand how two input signals can be combined and compared against a threshold to determine whether a simulated neuron fires.

How It Works

The program accepts two signal-strength values from the user.

It adds the two values to calculate the total signal.

It compares the total against a threshold of 10.

It displays an output based on the total signal strength.

Example

If the first signal is 4 and the second signal is 7, the total signal is 11.

Since 11 is greater than the threshold of 10, the program displays:

Neuron fired!

Python Concepts Learned

Variables

User input using input()

Converting input using int()

Arithmetic operations

Conditional statements (if, elif, and else)

Biomedical Engineering Connection

Neurons communicate through electrical activity. This program provides a simplified introduction to the concept of threshold firing and how computational models can represent basic biological processes.

Note: This is an educational model. It does not reproduce the full biological mechanisms of neurons.
